# Paper Reading Reports

This directory is the maintained deep-dive library for accepted papers.

Each report is updated across runs and should be linked from `05_registry_patch.json` through `deep_dive_path`. Run folders under `reports/runs/` keep audit artifacts only; final paper analyses live here.

## Branches

| Branch | Directory | Focus |
|---|---|---|
| A | `A_executable_world_representation/` | executable world structures, affordances, physical/deformable state |
| B | `B_interactive_generation_pcg/` | interactive generation, PCG, agentic simulation |
| C | `C_spatial_intelligence/` | spatial VLMs, 3D reasoning, tool-augmented spatial understanding |
| D | `D_vla_world_action_models/` | VLA policies, robot foundation models, world-action models |
| E | `E_evaluation_data_infrastructure/` | benchmarks, datasets, evaluation protocols, reproducibility |
