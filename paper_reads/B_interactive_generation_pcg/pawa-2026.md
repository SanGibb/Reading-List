## TL;DR

Introduces panoramic shared state and aligned multiplayer action data for scalable multi-agent world modeling. Direct source for SharedWorldFrame, PlayerAction, PanoramaState, ConcurrentAgent, and multiplayer consistency evaluation. Main caveat: the release is new and its reported results have not been independently reproduced.

## Novelty

- What is actually new: Introduces panoramic shared state and aligned multiplayer action data for scalable multi-agent world modeling.
- Difference from prior work: A dual-tower POV/panorama predictor uses cross-attention in a shared world frame and quadratic-phase player encodings.
- Why the delta matters: Direct source for SharedWorldFrame, PlayerAction, PanoramaState, ConcurrentAgent, and multiplayer consistency evaluation.

## Contributions

1. A dual-tower POV/panorama predictor uses cross-attention in a shared world frame and quadratic-phase player encodings.
